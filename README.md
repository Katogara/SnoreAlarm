# いびきアラーム (SnoreAlarm)

iPhone のマイクでいびきを検知し、バイブレーションで知らせて寝返り・起床を促す iOS アプリです。

- 画面をロックしても検知を続けます (バックグラウンドオーディオ)
- iPhone の振動か、Apple Watch の振動 (パートナーを起こさない) で知らせます
- 音声は端末内でリアルタイムに解析します。いびきと判定した数秒間だけを端末内に録音し (設定でオフにできます)、1 週間で自動削除します。外部への送信はしません
- 検知ログや録音一覧から、録音したいびきを再生できます
- 「〇分以内に〇回いびき」で振動。感度・回数・振動の長さ・開始までの待ち時間を設定可能
- 毎日寝る時刻に監視の開始を通知でお知らせし (通知から 1 タップで開始)、朝は自動で監視を終了できます (開始し忘れの防止)
- 一晩のいびきを、時刻といびきの大きさのグラフで確認できます

## 動作環境

- iOS 17 以降の iPhone (実機。シミュレータではマイクとバイブレーションを確認できません)
- Xcode 15 以降

## ビルド方法

### XcodeGen を使う (おすすめ)

```sh
brew install xcodegen
xcodegen generate
open SnoreAlarm.xcodeproj
```

Xcode で `SnoreAlarm` ターゲットの **Signing & Capabilities** に自分の Team を設定し、
必要なら Bundle Identifier (`com.example.SnoreAlarm`) を変更して、iPhone を接続して実行します。

### 手動で Xcode プロジェクトを作る場合

1. Xcode で新規 iOS App (SwiftUI, iOS 17) を `SnoreAlarm` という名前で作成
2. 自動生成された `ContentView.swift` と `SnoreAlarmApp.swift` を削除し、`SnoreAlarm/` 以下の Swift ファイルを追加
3. ターゲットの Info に以下を追加
   - `Privacy - Microphone Usage Description` (NSMicrophoneUsageDescription)
   - **Signing & Capabilities** > **+ Capability** > **Background Modes** > **Audio, AirPlay, and Picture in Picture** をオン
4. テストを使う場合は `SnoreAlarmTests/` を Unit Test ターゲットに追加

## Windows しかない場合 (Mac なしでインストール)

ビルドは GitHub Actions の macOS マシンで行い、できたアプリを Windows から
[Sideloadly](https://sideloadly.io/) で iPhone に入れます。必要なのは無料の Apple ID だけです。

### 1. アプリ (IPA ファイル) をダウンロード

1. GitHub のこのリポジトリの **Actions** タブ → **iOS Build** を開く
2. 一番上の緑色のチェックが付いた実行を開く (手動で作り直す場合は **Run workflow**)
3. ページ下部の **Artifacts** から `SnoreAlarm-unsigned-ipa` をダウンロードし、zip を展開して `SnoreAlarm.ipa` を取り出す

### 2. Windows の準備

1. Sideloadly をインストール
2. Sideloadly の案内に従って **iTunes** と **iCloud** をインストール
   (Microsoft Store 版ではなく、Apple 公式サイトからダウンロードできるインストーラー版を推奨)
3. iPhone を USB ケーブルで PC につなぎ、iPhone に出る「このコンピュータを信頼しますか?」で「信頼」

### 3. iPhone にインストール

1. Sideloadly を起動し、`SnoreAlarm.ipa` をウィンドウにドラッグ
2. 「Apple account」に自分の Apple ID を入力して **Start** (途中で Apple ID のパスワードや 2 段階認証コードを聞かれます)
   - Bundle ID のエラーが出る場合は **Advanced options** で Bundle ID を `com.<自分の名前>.SnoreAlarm` などに変更
3. iPhone の **設定 > プライバシーとセキュリティ > デベロッパモード** をオンにして再起動 (初回のみ)
4. **設定 > 一般 > VPN とデバイス管理** で自分の Apple ID の開発元を「信頼」
5. ホーム画面の「いびきアラーム」を起動

### 無料 Apple ID の制限

- インストールしたアプリは **7 日で起動できなくなります**。同じ手順で Sideloadly から入れ直すと延長できます
  (Sideloadly の自動更新機能を使うと、PC と iPhone が同じ Wi-Fi にあれば自動で再署名できます)
- 有料の Apple Developer Program (年額) に登録すれば 1 年有効になり、TestFlight 配布も可能です

## 使い方

1. iPhone を充電器につなぎ、枕元 (顔から 50cm〜1m 程度) に置く
2. 「監視を開始」をタップ (初回はマイクの許可を求められます)
3. そのまま画面をロックして就寝
4. いびきが続くと振動します。画面ロック中は通知も出ます (初回は通知の許可を求められます)。通知の「振動を止める」、またはアプリの「振動を止める」で止められます
5. 朝、「監視を終了」をタップ。ログでいびき・アラームの回数と時刻を確認できます。いびきの行の ▶ で録音を再生できます (左上の波形ボタンからは直近 1 週間の録音一覧を開けます)

### 知らせる端末 (iPhone / Apple Watch)

初回起動時に、いびきを知らせる端末を選びます。あとからメイン画面のスイッチ (左が iPhone、右が Apple Watch) で切り替えられます。監視中に切り替えても、次のアラームから反映します。

- **iPhone**: iPhone 本体が振動します。安定して動きます
- **Apple Watch**: 手首だけが振動するので、パートナーの睡眠を妨げません (Apple Watch のバージョンによっては動作が不安定になることがあります)
  - Watch 用のアプリは使いません。iPhone の通知が Watch に転送される仕組みを使い、振動の長さのあいだ繰り返し通知を送ります (最初の 3 回は 1 秒おき、そのあとは 2 秒おき。実機で 4.5 秒おきでは起きられなかったため)
  - 転送されるのは **iPhone の画面がロックされていて (手動でも自動ロックでも可)、Watch を着けてロックを解除しているとき**だけです。自動ロックが「なし」だと画面が消えず、Watch に届きません。Watch を外していると iPhone で通知音が鳴ります
  - Watch では、通知の「振動を止める」を押すか、通知をタップする・払いのけると止まります。アラームの間に送った通知は消さずに残し (次の通知で前の通知を消すと、押そうとしていたボタンが効かなくなるため)、アラームが終わったらまとめて消します
  - **Watch を消音モードにしてください** (コントロールセンターのベルのボタン)。消音モードにしないと Watch から通知音が鳴ります。消音モードでも振動では知らせます (実機で、消音モードでないと Watch が音を鳴らすことを確認済み)
  - いびきアラームの通知の許可と「サウンド」がオンかはアプリが自動で確かめます。オフのときだけ、準備の画面とメイン画面に「通知の設定を開く」ボタンが出て、通知設定を直接開けます (サウンドなしの通知は Watch に転送されません。実機で確認)。寝ているあいだに「睡眠」や「おやすみモード」がオンになる場合 (睡眠スケジュールや Watch の睡眠記録で自動でオンになります) は、そのままだと通知が止められるので、「設定」アプリ > 集中モード > 睡眠 (おやすみモードも同じ) > App で「いびきアラーム」を許可してください
  - 寝る前にメイン画面の「Watch に届くかテスト」で確かめられます。手順を動くイラストで説明する画面が開き、OK を押したらすぐに画面をロックすると、5 秒後に通知を出し、10 秒ほどで Watch に届きます (通知を出してから Watch に届くまでにも数秒かかります)
  - Watch に届かないと分かっているとき (ペアリングされていない・通知が許可されていない・画面が点いている) は iPhone で振動します
  - Watch に届いたかは iPhone から確かめられないため、Watch で知らせてから 5 分以内にまた振動の条件に達したら、iPhone も振動させます (設定でオフにできます)。「振動を止める」などで自分で止めたときは、起きたとみなして iPhone は振動させません
  - 今回の記録に、Watch に通知した回数と、代わりに iPhone で振動した回数を表示します

### 寝る時刻のお知らせと自動終了 (開始忘れの防止)

設定の「開始忘れの防止」で「寝る時刻のお知らせと自動終了」をオンにし、お知らせと自動終了の時刻を選びます (初期値 23:00 と 7:00)。

- 毎日お知らせの時刻に「いびきの監視を始めましょう」と通知します (通知音あり)。監視を始めるまで 15 分おきに 4 回まで繰り返します
- 通知の「監視を開始」(長押しまたは下にスワイプすると出ます) を押すか、通知をタップすると、アプリが開いて監視を始めます
- 先に「監視を開始」を押していれば、その夜は通知しません
- 通知の予約は iOS が持つので、アプリを終了していても届きます (7 日分を予約し、アプリを開くたびに先へ延ばします)
- 監視は自動終了の時刻に止まります (「監視を開始」を押して始めた場合も同じ)
- 監視が始まるまでマイクは使いません (イヤホンのマイクも使えます)

### いびきの録音

- いびきと判定した区間を前後 0.2〜0.3 秒の余白付きで、16kHz・モノラル・AAC 24kbps (ADTS 形式の .aac) で保存します (1 回あたり約 12KB 以下)
- 1 回の監視で保存するのは最大 1500 回分 (約 20MB) までです
- 録音はアプリの起動時と監視の開始時に、1 週間より古いものから自動で削除します。iCloud バックアップには含めません
- 監視中は、再生した音をいびきと誤検知しないよう再生できません
- 再生すると、その行の下に波形を表示します。左から右へ時間が進み、上下の大きさが音の大きさです。高さは録音したままの音量 (-60〜0 dB) なので、録音どうしでいびきの大小を比べられます (目安の線は -20 dB と -40 dB)。再生位置はオレンジの縦線で示し、再生が終わっても次の録音を再生するまで表示しておきます
- 録音はマイクの生の音量 (自動ゲイン調整なし) で保存するため小さめです。再生時に自動で音量を上げます (最大 +30dB)。消音スイッチがオンでも鳴りますが、iPhone の音量 (メディアの音量) が小さいと聞こえにくくなります
- 設定の「いびきを録音する」をオフにすると録音しません

### 一晩の記録

左上のグラフのボタンで、一晩のいびきをまとめて確認できます。

- 横が時刻、縦が録音したいびきの大きさ (録音したままの音量、-60〜0 dB) で、いびき 1 回を縦線 1 本で表示します。監視していた時間は色の付いた帯で示します
- 設定の「1日の区切り」(初期値 12:00) から翌日の区切りの前までに始めた監視を一晩とし、最初の開始から最後の終了までを表示します。夜中に何度か止めて再開しても一晩にまとまります。昼に眠る場合は区切りを起きている時間帯にします
- ピンチで拡大・縮小 (最大 3 分の範囲まで) し、拡大中は左右にスクロールできます。グラフの下のボタンでも拡大・縮小・全体表示ができます
- グラフをタップすると近くのいびきを選び、すぐに波形を表示します。再生もできます (前後のいびきへも移れます)
- 監視していた時間・いびきの回数・1 時間あたりの回数・合計の長さ・最大の音量・多かった時間帯も表示します
- 振動で知らせた時刻をオレンジの点線で示し、まとめに振動で知らせた回数と自分で止めた回数、下にその時刻と知らせた端末 (iPhone / Apple Watch / 両方) の一覧を出します (デモの振動は含みません)
- 録音をもとにしているので、録音をオフにしていた間や、1 週間より前の夜は表示されません。監視の開始・終了の時刻は端末内 (UserDefaults) に約 8 日分残します

### いびき検知デモ

監視していないときに「いびき検知デモ」をタップすると、設定した条件 (感度・回数・判定時間) を満たすいびきを疑似的に流し、実際の判定ロジックで検知 → 振動 (設定した長さ) までを再現します。マイクは使いません。いびき 1 回あたり約 2.5 秒かかります (4 回なら約 12 秒)。途中で「デモを終了」で止められます。

知らせる端末を Apple Watch にしているときは、デモでも Watch に通知します。「開始」を押したらすぐに iPhone の画面をロックしてください (いびきが始まるまで 5 秒長く待ちます。画面が点いたままだと iPhone が振動します)。

デモの途中で画面をロックすると、バックグラウンドで検知したときの通知と振動も確認できます。ただしデモはマイクを使わないため、ロック後に動けるのは iOS が許す 30 秒程度までです (回数が多い・振動が長い設定だと途中で終わります)。

## 検知の仕組み

`SnoreAlarm/Audio/` にあります。

| ファイル | 役割 |
| --- | --- |
| `SpectralAnalyzer.swift` | 約 43ms ごとの音声フレームから音量 (dBFS) と、40–600Hz 帯域のエネルギー比を FFT (Accelerate) で算出 |
| `SnoreDetector.swift` | 環境音の大きさ (ノイズフロア) を追従し、それより大きい音の区間を抽出。長さ 0.3〜3.5 秒・低音が支配的なものをいびきと判定し、設定した時間内に規定回数あればアラーム |
| `AudioProcessor.swift` | マイク入力 (AVAudioEngine のタップ) をフレームに分割して上記に渡す |
| `VibrationAlarm.swift` | `kSystemSoundID_Vibrate` を繰り返し鳴らす (バックグラウンドでも動作) |
| `SnoreRecorder.swift` / `SampleRingBuffer.swift` | マイク入力を 16kHz モノラルにして直近 6 秒だけ保持し、いびきの区間を切り出す (メモリは約 380KB で一定) |
| `DemoSignal.swift` | いびき検知デモ用に、設定どおりの回数のいびきを含む疑似フレーム列を作る |
| `SnoreMonitor.swift` | オーディオセッション管理、電話などの中断からの復帰、振動中の検知停止、自動終了など全体の制御 |
| `MonitoringSchedule.swift` (`SnoreAlarm/`) | 寝る時刻のお知らせを出す時刻と自動終了の時刻の計算 |
| `RecordingStore.swift` (`SnoreAlarm/`) | 録音の AAC 保存 (優先度の低いスレッド)・一覧・1 週間での自動削除。日時・長さ・最大音量はファイル名に入れる |
| `MonitoringSessionStore.swift` / `NightRecord.swift` (`SnoreAlarm/`) | 監視の開始・終了時刻の記録と、一晩ごとのまとめ (1日の区切りで分ける) |
| `AlarmNotifier.swift` | 画面ロック中にいびきで振動したとき・マイクを再開できなかったときのローカル通知 (「振動を止める」ボタン付き) と、寝る時刻のお知らせ (「監視を開始」ボタン付き) |

- 会話や TV の音 (高い周波数が多い) はいびきと判定しにくくなっています
- エアコンや扇風機のような続く音は自動的に環境音として取り込みます
- 振動音を拾って誤検知しないよう、振動中とその後 2 秒は検知を止めます

## 注意事項

- 一晩中マイクを使うため電池を消費します。充電しながらの使用をおすすめします
- 「設定」 > 「アクセシビリティ」 > 「タッチ」 > 「バイブレーション」がオフだと振動しません
- アプリを上にスワイプして終了すると監視も止まります
- 同室の人のいびきや寝言にも反応することがあります。誤検知が多い場合は設定で感度を下げるか回数を増やしてください
- 医療機器ではありません。睡眠時無呼吸症候群などが心配な場合は医療機関に相談してください

## 診断ログ (開発用。リリース前に無効にする)

不具合の調査用に、監視中の様子をファイルに記録しています。設定画面のいちばん下の「診断 (開発用)」から書き出して共有できます (録音した音そのものは含みません)。

- 1 分ごとのマイク入力の集計 (受け取ったバッファ数・音量・ノイズフロア・しきい値・いびきと判定しなかった理由の内訳)
- 1 分ごとの状態 (アプリが前面か・画面ロック・オーディオセッション・入力経路・マイクのミュート)
- オーディオの中断・経路の変更・画面ロック・メモリ不足などの出来事と、画面のログと同じ内容

**リリース時は `project.yml` の `SWIFT_ACTIVE_COMPILATION_CONDITIONS: "$(inherited) DIAGNOSTICS"` の行を消してください。** ログを書かなくなり、設定画面の項目も表示されなくなります (`DiagnosticLog.write` の呼び出しは残っていても何もしません)。
